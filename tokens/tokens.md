# Design Tokens

> Тут зберігаються дизайн-токени проєкту — кольори, типографіка, відступи, радіуси тощо.
> Після узгодження концепту — перенести у `tokens.json` або CSS-змінні.

## Кольори

### Base palette

| Token | Value | Призначення |
|---|---|---|
| `color-cream` | `#FAF7F2` | Фон сторінки |
| `color-sand` | `#E8E0D0` | Вторинний фон, бордери |
| `color-terracotta` | `#C4622D` | Основний акцент, CTA |
| `color-amber` | `#D4820A` | Альтернативний акцент |
| `color-green-soft` | `#5A8A6A` | Статус "знайшов дім" |
| `color-text-primary` | `#2C2420` | Основний текст |
| `color-text-secondary` | `#7A6E68` | Допоміжний текст |

### Status badges

| Token | Value | Hex |
|---|---|---|
| `status-available` | `color-terracotta` | `#C4622D` |
| `status-pending` | `color-amber` | `#D4820A` |
| `status-adopted` | `color-green-soft` | `#5A8A6A` |
