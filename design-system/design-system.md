# Design System

> Документація дизайн-системи Prytulok. Компоненти, патерни, принципи.

## Принципи

- **Тепло та домашність** — жоден елемент не має виглядати як SaaS-продукт
- **Фото — герой** — картки тварин будуються навколо фото, текст — допоміжний
- **Мінімум кроків** — від каталогу до заявки максимум 2 кроки
- **Mobile-first** — breakpoints: 375 / 768 / 1280
